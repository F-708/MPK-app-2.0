# Как пользоваться редактором карты

Файл `editor.html` открывается двойным щелчком. Интернет и папка с проектом
не нужны — всё внутри файла. Разметка сохраняется сама, даже если закрыть
вкладку.

---

## Порядок работы

1. **Открыть `editor.html`**
2. **«Загрузить rooms.json»** (раздел «Файлы» внизу панели) — появятся
   188 кабинетов с номерами
3. **«Выровнять этаж»** — прижмёт рамки к стенам
4. **Инструментом «Статус»** пройтись по кабинетам, которых нет
5. **«Коридор»** и **«Узел»** — разметить проходы
6. **«Вход»** — отметить входы стрелками
7. **«Сохранить JSON»** → файл `map-data.json` отдать разработчику

---

## Мышь

| Действие | Что делает |
|---|---|
| Колесо | Приблизить / отдалить |
| Пробел + тянуть | Сдвинуть план |
| Клик по объекту | Выбрать |
| Shift + клик | Добавить к выделению |
| Тянуть по пустому месту | Рамка выделения — выделит всё внутри |
| Тянуть за выделенное | Двигать |

Кнопки **−**, **«По экрану»**, **+** в правом нижнем углу — то же самое.

## Инструменты

Переключаются кнопками слева или клавишами.

### Выделять (V)
Основной режим. Выбрать кабинет, подвинуть его, выделить несколько рамкой.
При выделении одного кабинета в панели появляется «Выбранный кабинет» —
там можно вписать номер, название, заметку, статус и точные координаты.

### Кабинет (R)
Два способа:
- **Кликнуть внутри кабинета** — рамка определится сама по стенам
- **Протянуть рамку примерно** — она тоже прижмётся к стенам

В обоих случаях сразу откроется окно с номером, и **номер уже подставлен
следующим по порядку** — чаще всего достаточно нажать «Ок».

### Статус (S)
В панели «Настройки инструмента» выбрать статус, потом **кликать по
кабинетам подряд**. Так быстро проставляется «не существует» десятку
кабинетов.

Четыре статуса:
- **Обычный** — синяя рамка
- **Закрыт** — серая пунктирная
- **Не существует** — серый с крестом накрест (кабинеты, которых на плане
  нет или в которые не попасть)
- **Служебный** — зелёный пунктир

### Коридор (C)
Кликами вести ломаную по коридору. **Enter** или **двойной клик** —
закончить, **Esc** — отменить. Толщина настраивается в панели.

### Узел (N)
Перекрёсток коридоров — из них потом строятся маршруты.
Первый узел просто ставится. Второй **автоматически соединяется с ним
линией**. Дальше третий соединяется со вторым и так далее.
**Esc** — разорвать цепочку и начать новую.

### Вход (E)
Сначала выбрать в панели направление (вправо / вниз / влево / вверх),
потом кликнуть. Получится стрелка, показывающая, куда входят.
Название вводится после клика, тип (главный вход / запасной выход /
лестница) определяется по названию.

### Подпись (T)
Клик — ввести текст. Просто надпись в нужном месте плана.

### Выноска (O)
Сначала клик **по кабинету**, потом клик **в стороне**. Введи текст —
получится надпись с пунктирной линией к кабинету. Для важных кабинетов,
о которых надо сказать отдельно.

### Маршрут (M)
Готовый путь ломаной, отдельным слоем. Enter — закончить.

### Линейка (L)
Протянуть отрезок — покажет длину. Если в панели указать, **сколько метров
в ширине плана**, линейка начнёт показывать и метры. Указывается один раз.

### Ластик (X)
Клик по объекту — удалить.

### Двигатель (пробел)
То же, что пробел с мышью — сдвинуть план.

## Панель слева

Сверху вниз:

- **Этаж** — 1 / 2 / 3 и 4
- **Инструмент** — 12 кнопок и «Отменить» / «Вернуть»
- **Настройки инструмента** — появляется только когда нужна: выбор статуса,
  направление входа, толщина коридора, масштаб в метрах
- **Умная разметка** — два тумблера и две кнопки:
  - *Прижимать рамку к стенам* — включает автоконтур
  - *Ровнять с соседями* — грани ровняются по краям уже размеченных
    кабинетов, чтобы ряды не «плясали»
  - **«Выровнять этаж»** — прогнать автоконтур по всем кабинетам сразу
  - **«Найти кабинеты»** — найти замкнутые области на плане и создать их
    как кабинеты. Помогает, если каких-то кабинетов не хватает
- **На плане** — счётчики объектов
- **Кабинеты** — поиск, фильтр по статусу и кнопка **«Выделенным…»**
  (массовые операции)
- **Список кабинетов** — клик центрирует карту на кабинете
- **Выбранный кабинет** — поля для правки
- **Слои** — что показывать на плане, и **прозрачность плана**
  (удобно размечать коридоры поверх чертежа)
- **Файлы** — сохранение и загрузка

## Кнопка «Выделенным…»

Выделите кабинеты (рамкой или Shift+клик), нажмите кнопку и введите цифру:

| Цифра | Что сделает |
|---|---|
| 1 | статус «обычный» |
| 2 | статус «закрыт» |
| 3 | статус «не существует» |
| 4 | статус «служебный» |
| 5 | **впишет номера по порядку** — слева-вправо, сверху-вниз |
| 6 | удалит выделенные |

## Горячие клавиши

| Клавиша | Действие |
|---|---|
| `V` `R` `S` `C` `N` `E` `T` `O` `M` `L` `X` | инструменты |
| `Пробел` | двигать план |
| `Enter` | закончить коридор или маршрут |
| `Esc` | отменить начатое |
| `Delete` | удалить выделенное |
| `Ctrl+Z` / `Ctrl+Y` | отменить / вернуть (80 шагов) |
| `Ctrl+A` | выделить все кабинеты этажа |
| `Ctrl+S` | сохранить файл |

## Файлы

- **Сохранить JSON** — скачать `map-data.json`. Это итоговый файл для
  разработчика: в нём кабинеты, статусы, коридоры, узлы, маршруты, входы.
- **Открыть JSON** — продолжить работу с ранее сохранённым файлом
  (**заменяет** текущие данные)
- **Загрузить rooms.json** — подгрузить готовые кабинеты
  (**добавляет**, существующие обновляет по номеру)
- **Экспорт SVG / PNG** — картинка с разметкой, для проверки и показа
- **Очистить этаж** — удалить всю разметку текущего этажа

## Если что-то не так

**Рамка не прижимается к стенам.** Проверьте, что включён тумблер «Прижимать
рамку к стенам», и что план уже загрузился (при открытии на секунду
появляется надпись «План разобран»).

**Автоконтур тянет рамку не туда.** Выключите тумблер и выставьте рамку
руками — в панели «Выбранный кабинет» есть точные координаты.

**Кабинет создался лишний.** Инструмент «Ластик», клик по нему.

**Пропала разметка.** Откройте сохранённый JSON. Данные также хранятся
в браузере и переживают перезагрузку страницы.
