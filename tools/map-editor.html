Как пользоваться (5 шагов)
  1. Загрузите фон: кнопка «Фон этажа» (или перетащите картинку плана на поле). Для каждого этажа — своя картинка: map_floor1.jpg, map_floor2.jpg, map_floor34.jpg.
  2. Откройте карту: кнопка «Открыть карту» → выберите college_map.json из приложения. Все комнаты, коридоры, узлы и лестницы появятся на плане.
  3. Правьте: клик — выбрать объект (свойства справа), перетаскивание — двигать, угловые квадратики — менять размер комнаты. «Снап» помогает выравнивать комнаты вплотную. Инструменты сверху добавляют комнаты / коридоры (кликами по точкам) / узлы / входы и лестницы. Двери: выберите комнату → «Добавить дверь» → клик по краю комнаты.
  4. Сохраните: кнопка «Сохранить карту» скачает college_map.json — отдайте файл разработчику, он встанет в приложение без изменений.
  5. Страховка: Ctrl+Z — отмена (до 50 шагов), правая кнопка мыши или пробел + тянуть — двигать вид, колесо — зум. Автосохранение в браузере — кнопка «Восстановить».
