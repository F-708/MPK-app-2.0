# Промпт: редактор планов этажей

Отдать нейросети **вместе с тремя изображениями планов** в одном чате.
Результат — один HTML-файл.

---

Ты — senior фронтенд-разработчик. Сделай **один HTML-файл** — редактор планов
этажей колледжа. В ответ отдай **только готовый код файла**, без пояснений.

## Входные данные

Три изображения: план 1 этажа, план 2 этажа, общий план 3 и 4 этажей.
Это схемы здания колледжа с номерами кабинетов.

## Общие требования

- Всё в одном файле: HTML + CSS + JS. **Без внешних библиотек, без интернета,
  без сборки** — открывается двойным щелчком.
- Изображения **встрои в файл** как `data:image/...;base64`, чтобы страница
  работала из любой папки и без исходных картинок рядом.
- **Все координаты хранятся в долях от размера картинки: 0..1.** Никогда
  в пикселях — план могут заменить на другой размер.
- Интерфейс на русском языке.

## Экран

- Слева панель инструментов шириной 320 px, справа сцена.
- Сверху вкладки этажей: «1 этаж», «2 этаж», «3 и 4 этажи».
- Сцена: план, зум колесом (0.4x–8x), панорама (пробел + тянуть мышью,
  средняя кнопка мыши или инструмент «Двигать»). Зум не должен улетать
  за пределы плана — план всегда занимает экран.
- Все нарисованные объекты лежат в **отдельном слое поверх картинки**
  и масштабируются вместе с ней.

## Инструменты

1. **Выделять** — выбор объектов, рамка выделения, Shift добавляет к выделению.
2. **Кабинет** — тянешь рамку, создаётся кабинет.
3. **Коридор** — кликами ставишь точки ломаной; Enter или двойной клик
   заканчивает, Esc отменяет. Толщина линии настраивается.
4. **Узел** — точка на плане (перекрёсток коридоров). Новый узел соединяется
   линией с ранее выделенным узлом.
5. **Подпись** — клик, вводишь текст, текст перетаскивается.
6. **Выноска** — клик по объекту, затем клик в стороне: текст с линией-указателем
   к этому объекту (для важных кабинетов).
7. **Маршрут** — кликами строишь ломаную пути.
8. **Вход** — точка с типом: главный вход / запасной выход / лестница.
9. **Ластик** — клик удаляет объект.
10. **Линейка** — тянется отрезок, показывает длину в долях и в метрах
    (масштаб задаётся один раз: «сколько метров в ширине плана»).

## Кабинет: что можно задать

- **Номер** — главное поле
- **Название помещения** — необязательно («Библиотека», «Актовый зал»)
- **Заметка** — свободный текст
- **Статус**: обычный / закрыт / не существует / служебный.
  Визуально: обычный — синяя рамка; закрыт — серая с замком;
  **не существует — серая с крестом накрест**; служебный — пунктирная рамка.
- **Цвет подсветки** — необязательно

## Слои

Отдельные переключатели видимости: кабинеты, номера кабинетов, коридоры, узлы,
подписи, выноски, маршруты, входы.
Плюс **ползунок прозрачности плана** — чтобы чертёж не мешал, когда смотришь
на разметку.

## Список слева

- Счётчики: сколько объектов каждого типа
- Список кабинетов: номер, статус, название
- **Поиск** по номеру и названию, **фильтр по статусу**
- Один клик по кабинету — карта центрируется на нём
- Двойной клик — редактирование

## Правки

- **Undo/Redo не меньше 50 шагов** (Ctrl+Z, Ctrl+Y)
- Копировать / вставить (Ctrl+C, Ctrl+V), дублировать (Ctrl+D)
- Удалить (Delete); мультивыделение рамкой, перемещение выделенных
- **Выровнять**: по левому / правому / верхнему / нижнему краю,
  по центру по горизонтали и вертикали
- **Распределить равномерно** по горизонтали и вертикали
- **Прилипание** к границам соседних кабинетов и к сетке (шаг 0.5%),
  включается галочкой
- **Точный ввод**: для выделенного кабинета поля x, y, w, h с шагом 0.0001

## Сохранение

- **Автосохранение в localStorage** после каждого действия, при открытии — восстановление
- «Сохранить файл» — скачивается `map-data.json`
- «Загрузить файл» — выбрать .json, данные заменяют текущие (с подтверждением)
- «Экспорт SVG» и «Экспорт PNG» — картинка с разметкой поверх плана

## Формат JSON — строго такой

```
{
  "version": 1,
  "scaleMeters": число_или_null,
  "floors": {
    "1":   { "rooms": [], "corridors": [], "nodes": [], "labels": [],
             "callouts": [], "routes": [], "entrances": [] },
    "2":   { ... },
    "3-4": { ... }
  }
}
```

Объекты:

```
room      { id, number, title, note, status, x, y, w, h }
corridor  { id, points: [[x,y], ...], width }
node      { id, x, y, links: ["id", ...] }
label     { id, x, y, text, size }
callout   { id, text, x, y, targetId }
route     { id, points: [[x,y], ...], color }
entrance  { id, x, y, kind: "main" | "backup" | "stairs", title }
```

## Загрузка готовой разметки

В панели обязательно должна быть кнопка **«Загрузить rooms.json»**.
Файл такого вида:

```
{ "version": 1,
  "floors": {
    "1": { "rooms": [ { "id": "...", "number": "101",
                        "x": 0.4927, "y": 0.2411, "w": 0.0138, "h": 0.0452,
                        "status": "normal", "title": "", "note": "" } ] }
  }
}
```

При загрузке кабинеты добавляются к текущим. Координаты — в долях,
**x и y это ЦЕНТР рамки**, w и h — её размер.

## Помощь при разметке

- Если ты видишь на плане кабинеты — **расставь для них рамки заранее**,
  примерно, по своему усмотрению. Пользователь потом поправит. Лучше примерно,
  чем ничего.
- Для нового кабинета — кнопка **«Предложить номер»**: подставляет следующий
  свободный номер по порядку для этого этажа (например, если уже есть 101 и 102,
  предложит 103).

## Горячие клавиши

`V` выделять · `R` кабинет · `C` коридор · `N` узел · `T` подпись ·
`M` маршрут · `E` вход · `Del` удалить · `Ctrl+Z` отмена · `Ctrl+Y` повтор ·
`Ctrl+S` сохранить файл · `Ctrl+D` дублировать · `Space` панорама · `Esc` отмена

## Как пользоваться

1. Открой новый чат с нейросетью, способной читать изображения.
2. **Приложи три картинки планов** и вставь этот промпт одним сообщением.
3. Получишь HTML-файл — сохрани и открой двойным щелчком.
4. Нажми **«Загрузить rooms.json»** и подай файл `rooms.json` — подтянутся
   188 готовых кабинетов, размечать заново не нужно.
5. Дальше расставляй статусы, коридоры, узлы, подписи.
6. «Сохранить файл» → `map-data.json` — этот файл отдать разработчику.

## Мелочи, которые стоит проверить в готовой странице

- Картинки точно встроены и видны
- Импорт `rooms.json` подхватывает все 188 кабинетов
- Экспорт даёт именно тот формат JSON, что описан выше
- Работает без интернета (отключи сеть и обнови страницу)
