## Вывод

Граф коридоров/узлов в college_map.json **уже полностью связен** — от каждой
комнаты есть путь до входа/лестницы на всех 3 этажах. Это значит:

1. **Мультиэтажный маршрутизатор (findMultiFloorRoute) работоспособен СЕЙЧАС** на
   существующих данных — corridors/nodes переразмечать с нуля НЕ НУЖНО.
2. Лестницы уже размечены (entrances kind="stairs") и сопрягаются между этажами
   по близости (0.007–0.041, см. MASTER-PLAN 2.3).
3. Осталось для Фазы 2.3: (а) пометить какие лестницы usable по списку заказчика
   (1эт 131/115/136/147/круговая; 2эт 241/238/230; 3эт 335/332/301/317; 4эт 401),
   (б) подключить findMultiFloorRoute к CollegeMapScreen + отрисовка пути/стрелок,
   (в) логика «откуда» (1-я пара → главный вход; иначе → кабинет текущей пары).

Vision-агенты нужны ТОЛЬКО для верификации usable-статуса лестниц и уточнения
рамок комнат (refinement), НЕ для построения графа. Экономит массу работы.
