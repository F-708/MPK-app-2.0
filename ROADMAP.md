# Мой Политех — требования и статус

Все пожелания, высказанные по ходу разработки, с отметкой о состоянии.
Обновлять при каждом изменении. Версия: **2.12** (versionCode 14).

## Сборки

| Вариант | applicationId | Иконка | База учащихся |
|---|---|---|---|
| standard (продакшн) | `com.aistudio.mpkschedule.vbyqzt` | синяя | **НЕТ** |
| admin | `com.aistudio.mpkschedule.vbyqzt.admin` | золотая | да, 1703 записи |

> **Требование безопасности:** в обычную версию база студентов не попадает ни при каких
> условиях — чтобы данные не могли утечь. Проверяется после каждой сборки:
> `unzip -l app-standard-release.apk | grep -c students.csv` должен вернуть `0`.
> Обе версии собираются вместе, об изменениях в admin сообщается отдельно.

## Сделано

### Расписание
- Парсинг .doc с guo-mpk.by (учащиеся и преподаватели), три стратегии разбора
- Символы рамок Word (U+2500–U+25FF) сохраняются при извлечении текста — без них таблица рассыпается
- Отсутствие группы в документе: понятное сообщение вместо пустого экрана
- Проверено: групп 41Т, 41С, 13Э, 42М, 42Э нет в публикуемых колледжем документах (15–17.09)

### Интерфейс
- Тёмная тема удалена
- Панель дня: «Сегодня» / «Завтра»
- Экран звонков: вертикальный таймлайн, пульсирующая точка не касается рамки карточки,
  инфочас помечен «ИНФОЧАС», уроки — «N УРОК», без переноса строк
- Убраны: шестерёнка в шапке, кнопка «избранное», кнопки вставки/файла, панель «МЕНЮ»
- Сокращения предметов берутся из документа, не выдумываются
- Диагностика спрятана в «Другое» (за отладочным переключателем)
- ФИО в карточке ученика — в две строки, без обрезки; «4 курс-курс» исправлено

### Преподаватели
- Карточка с крупным фото, 5 подвкладок: контакты, дисциплины, «у вашей группы», расписание
- Расписание преподавателя: сегодня / завтра / календарь (разбор `raspisanie-prepodavatelej.doc`)
- Переход в карточку по нажатию на преподавателя в расписании
- `TeacherInsights`: сопоставление ФИО из расписания с официальной базой, включая обрезанные фамилии
- Преподаватели выбранной группы поднимаются наверх и подсвечиваются как активные

### Звонки и напоминания
- Виджет: «до звонка N мин» (убрано фиксированное «0815»)
- Постоянное уведомление с обратным отсчётом, выключено по умолчанию,
  4 стиля × 5 цветовых тем
- `BellTimerService` — foreground-сервис с тиком по границе минуты (AlarmManager
  тормозится Doze, из-за этого виджет и уведомление замирали)
- Настройки: время уведомлений 10:00–21:00, лишняя строка «14:00–21:30» убрана

### Admin-версия
- База учащихся с фильтрами, поиск «где сейчас»
- Карточка ученика: сведения, «где сейчас», преподаватели группы, предметы,
  расписание группы — переключатель **Сегодня / Завтра / Календарь**
- Исправлена стрелка «назад»

### Производительность
- Архив расписания ограничен 60 днями (`ScheduleRepository.pruneOldLessons`) —
  иначе база росла бы бесконечно, каждый день синхронизации добавляет дату
- Даты сортируются по году/месяцу/дню, а не как строки «дд.ММ.гггг»
- Вкладки переключаются без анимации и лишней перерисовки

### Тесты
75 модульных тестов, 0 падений. Ключевые: `TeacherInsightsTest`,
`TeacherScheduleParserTest`, `UiRenderSmokeTest` (ловит падения композиции),
`ScheduleArchiveTest`.
