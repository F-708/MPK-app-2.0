# Проверка редактора карты

Редактор — обычная HTML-страница, и «посмотреть глазами» её недостаточно:
нужно убедиться, что она запускается и что до каждой кнопки реально
можно добраться.

## Как запустить

```bash
cd .testenv
npm install            # один раз: jsdom и puppeteer (скачает Chromium)
node test-browser.js   # главная проверка — в настоящем браузере
node test-editor.js    # быстрые проверки без браузера
node test-contour.js   # алгоритм прижатия к стенам
```

Все три должны закончиться словами «провалено 0».

## Что проверяет test-browser.js

Главное отличие от остальных: он проверяет **доступность** кнопок, а не
только наличие обработчика. Для каждой кнопки выясняется, видна ли она,
не перекрыта ли и попадает ли в неё клик. Именно такой проверки не хватало,
когда панель не прокручивалась и нижние кнопки были недостижимы.

Проверяется: запуск без ошибок, 22 кнопки достижимы, все 12 инструментов
включаются, стрелки входов и выбор направления, загрузка rooms.json через
кнопку, прижатие сдвинутой рамки к стенам, отмена и возврат, простановка
статуса кликом, выделение одного кабинета и рамкой, поиск, сохранение и
восстановление после перезагрузки.

Скриншоты каждого шага — в `shots/`.

## Чего эти проверки не покрывают

- Перетаскивание мышью с зажатой кнопкой по плану (частично покрыто
  выделением рамкой)
- Экспорт PNG и скачивание файлов — браузер в headless не пишет файлы
- Как выглядят мелкие детали на реальном экране телефона
