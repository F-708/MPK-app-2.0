# Проверка редактора

Редактор — обычная HTML-страница, её мало «посмотреть глазами»: нужно
убедиться, что она запускается и все действия работают. Для этого здесь
два сценария на jsdom.

## Как запустить

```bash
cd .testenv
npm install jsdom     # один раз
node test-editor.js   # запуск, интерфейс, разметка, экспорт
node test-contour.js  # прижатие рамок к стенам
```

Оба должны закончиться словами «провалено 0».

## Что проверяется

`test-editor.js` — страница открывается без ошибок, собираются все кнопки и
слои, переключаются этажи, загружаются 188 кабинетов, рисуются коридоры,
узлы и входы, работает экспорт и сохранение в браузере.

`test-contour.js` — на синтетическом плане со стенами: находит ли редактор
линии стен, прижимает ли к ним рамку, не трогает ли её при выключенном
автоконтуре и правильно ли расширяет стены для поиска комнат.

## Чего эти тесты не покрывают

Запустить по-настоящему браузер здесь нельзя, поэтому не проверены:
растеризация плана через canvas (от неё зависит автоконтур на живом плане),
зум колесом, перетаскивание мышью и экспорт PNG. Это надо смотреть руками.
