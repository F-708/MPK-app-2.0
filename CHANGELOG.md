# Журнал изменений

## 2.2 (2026-10-20)

### Новое

- Тёмная тема: переключатель в настройках, все экраны в тёмной палитре,
  выбранный цвет интегрирован, системные бары темнеют.
- Компактное расписание: переключатель в настройках — номер, предмет,
  преподаватель и кабинет без времени, карточки заметно тоньше.
- Режим «Я преподаватель» при первом запуске: выбор по фамилии/имени,
  расписание преподавателя с группами вместо ФИО, без вкладки «Уроки».
- Открытие документов из других приложений (Telegram и пр.): «куда положить»,
  файл запоминается по содержимому и потом открывается сразу.
- Переименование предметов в «Моей специальности» (со звёздочкой «*»).
- Оценки: удаление всех оценок предмета из его настроек; веса категорий
  теперь настраиваются на самом предмете.
- Резервная копия данных: выбор, что сохранить (расписание, задания, оценки,
  названия предметов, настройки).
- Первая настройка группы — в стиле «Расписание группы», плюс выбор подгруппы.

### Исправлено

- Домашние задания снова видны в расписании: устранено расхождение названий
  предметов (добавлены недостающие соответствия, сравнение терпит опечатки).
- Счётчик страниц DOCX показывает правильное число страниц.
- Маршруты на карте строго ортогональны, без крюков и сбоящих стрелок.
- Настройки: «Строка до звонка» — настройки за шестерёнкой, стили без лишних
  превью; при включении отсчёта приложение просит доступ к будильникам.
- Темы строки уведомлений и виджетов: «Системная» и «Как в приложении».

### Изменено

- Пакет приложения — com.politex (обновление со старой версии = переустановка).
- База учащихся: добавлена группа 43Э (admin-сборка).

## 2.1 (2026-10-16)

### Новое

- Автообновление из GitHub: приложение периодически проверяет репозиторий,
  скачивает новый APK и предлагает установить (standard-сборка).

### Исправлено

- Кружок темы «Как в приложении» в настройках строки уведомлений теперь
  меняет цвет сразу при смене темы, без перехода между вкладками.
- Удалена мёртвая настройка свайпа вкладок.

### Изменено

- Версия приложения переведена на 2.1 (versionCode 21000) для всех сборок.

## 2.0 (2026-10-13)

- Раздаточная линия для студентов: темы виджетов «как в приложении»,
  карта-баннер, превью виджетов, сжатие фото, рисование убрано из WebView.

## 1.x

- Расписание по группам, виджеты, карта колледжа, задания, оценки,
  материалы, каталог преподавателей, звонки.
