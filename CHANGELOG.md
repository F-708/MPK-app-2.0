# Журнал изменений

## 2.1 (2026-10-16)

### Новое

- Автообновление из GitHub: приложение периодически проверяет репозиторий,
  скачивает новый APK и предлагает установить (standard-сборка).

### Исправлено

- Кружок темы «Как в приложении» в настройках строки уведомлений теперь
  меняет цвет сразу при смене темы, без перехода между вкладками.
- Удалена мёртвая настройка свайпа вкладок.

### Изменено

- Версия приложения переведена на 2.1 (versionCode 21000) для всех сборок.

## 2.0 (2026-10-13)

- Раздаточная линия для студентов: темы виджетов «как в приложении»,
  карта-баннер, превью виджетов, сжатие фото, рисование убрано из WebView.

## 1.x

- Расписание по группам, виджеты, карта колледжа, задания, оценки,
  материалы, каталог преподавателей, звонки.
