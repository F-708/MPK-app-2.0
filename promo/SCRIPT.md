# «Мой Политех» — промо-ролик: сценарий + стилевая библия
**Статус:** v0.3 — пересобран по иерархии ценностей заказчика (уроки/звонки→люди→данные→карта→темы вскользь). v0.1/v0.2 = SCRIPT_v0.1.md / SCRIPT_v0.2.md. Ролик ещё не производится.
**История:** v0.1 — первый посекундный драфт; v0.2 — убран «авиарежим» (A3) и заменена сцена A6 на более сильную ценность.
**Формат основной:** 9:16, 1080×1920, 30 fps (сторис / VK Клипы / Telegram). Адаптация 16:9 — п. 3.7.
**Длительность:** Вариант А = 30 с (900 кадров), Вариант Б = 45 с (1350 кадров). Рекомендуемый: **А** — плотнее, досматриваемость выше.

## 1. Логлайн и аудитория

**Логлайн:** «Весь колледж — в одном кармане: расписание, кабинет, материалы и звонок. Без бумаги, без сайта, без интернета.»

**Целевая аудитория:**
- **Первичная:** студенты колледжа (15–20 лет), особенно первокурсники — им нужны карта и маршрут; смотрят вертикально, без звука первые 2 секунды → титры обязаны продавать сами.
- **Вторичная:** родители — им важны оценки, уведомления и «ребёнок не опоздает».
- **Месседж-иерархия:** 1) расписание всегда под рукой, 2) не заблудишься, 3) уроки/оценки в одном месте, 4) работает офлайн.

**Акцентный цвет (на утверждение):** красный НЕ используем. База — фирменный синий **#0072CE** (активный) / **#0B3564** (тёмный). Один контрастный для подписей и подсветок — **тёплый янтарный #FFB020**: читается на белом и на синем, не конфликтует с брендом, «студенческий», не тревожный. Заказчик сказал «туда-сюда красненько с текстом» — интерпретируем как бегущие акцентные подписи; делаем их янтарными с синей обводкой-подложкой.

### 1.1 ПРАВИЛО АУТЕНТИЧНОСТИ (важнее всех остальных)
Всё, что ВНУТРИ экрана мокапа, — только реальный интерфейс приложения, снятый скриншотом/скринкастом с устройства: реальная светлая тема, реальные строки, реальные анимации приложения (бегущие шевроны маршрута, точка звонков, undo-снекбар, пульс). Запрещено: дорисовывать элементы UI, которых нет в приложении (иконки «авиарежима» внутри приложения, count-up цифр, фейковые плашки), ускорять/замедлять жесты приложения в скринкасте, показывать вымышленные функции. Видео-язык (титры, янтарные выноски, стрелки-каллout'ы СНАРУЖИ экрана, Ken Burns камеры, переходы) — допускается, но выноски никогда не лежат поверх UI так, чтобы их можно было принять за часть приложения. Каждая сцена ниже помечена источником: [СКРИН] статичный скриншот или [СКРИНКАСТ] запись жеста.

## 4. Стилевая библия

### 4.1 Палитра
| Роль | Hex | Где |
|---|---|---|
| Фирменный тёмно-синий | `#0B3564` | финальный кадр фон, тёмные титры |
| Активный синий | `#0072CE` | подложки кнопок, обводки, CTA |
| Акцент подписей (янтарь) | `#FFB020` | ровно ОДИН акцент на кадр: обводки, стрелки, точки |
| Фон сцен | `#F4F6F8` | светло-серый, как светлая тема приложения |
| Текст титров | `#111820` | почти чёрный, не чистый #000 |
| Вторичный текст | `#5B6B7A` | подтитры, мелкие подписи |

Запрещено: красный, градиенты-радуги, второй акцентный цвет в одном кадре.

### 4.2 Шрифты (Google Fonts, лицензия OFL, кириллица есть)
- **Golos Text** — единственный шрифт. 900 для заголовков-титров, 500 для подтитров, 400 для мелочи. Системная альтернатива, если Google Fonts не подключить: Roboto.
- Секундомер «до звонка» и цифры среднего балла — **JetBrains Mono 700** (моноширинный, не прыгает).
- Подключение в Remotion: `@remotion/google-fonts/GolosText`.

### 4.3 Типографика и отступы (для 1080×1920)
- Титр-заголовок: **76 px**, 900, межстрочный 1.05, ≤ 30 символов, в 2 строки максимум.
- Подтитр: **44 px**, 500.
- Отступы安全 safe area: **96 px** слева/справа, **220 px** сверху и снизу (под UI сторис-плееров).
- Титр — всегда на подложке: белая плашка `rgba(255,255,255,0.94)`, скругление **24 px**, тень `0 8px 32px rgba(11,53,100,0.18)`. Янтарные слова внутри тёмного титра — наоборот, на синей плашке #0B3564.

### 4.4 Мокап телефона
- Рисуем CSS-рамкой, без PNG-ассетов: внешний корпус `#111820`, скругление **56 px**, border 14 px, внутренний экран — скриншот со скруглением 42 px. Динамик-«таблетка» — овал 140×28 px сверху.
- Тень: `0 40px 80px rgba(11,53,100,0.25)` + лёгкая `0 8px 16px rgba(0,0,0,0.12)`.
- Размер на кадре 9:16: ширина мокапа **860 px** (80% ширины), высота по скриншоту.
- Скриншоты масштабируются `object-fit: cover` в область экрана.

### 4.5 Скорости анимаций
| Движение | Длительность | Кривая |
|---|---|---|
| Вход мокапа | 550 мс | `spring({damping: 200, stiffness: 120})` |
| Вход титра (fade + y 24→0) | 300 мс | ease-out |
| Ken Burns внутри экрана | 3000–5000 мс | linear, scale ≤ 1.06–1.35 |
| Переход fade / slide | 300 / 350 мс | ease-in-out |
| Акцент (обводка/стрелка pop-in) | 250 мс | spring damping 150 |
| Янтарная пульсация точки | 1200 мс цикл | sin |

Принципы: **не мельтешить** — одна анимация-событие на сцену; **один акцент на кадр**; мокап никогда не трясётся; движение камеры медленнее, чем кажется нужным (×0.7 от первого порыва).

### 4.6 Переходы
Только три: cut (внутри блока фич), slide 350 мс (смена вкладок — повторяет жест приложения), match-cut (A3→A4 иконка→иконка, A9→A10 тап→вспышка). Никаких 3D-кубов, глитчей, шторок.

### 4.7 Адаптация 16:9 (1920×1080)
Композиция та же, layout меняется: мокап — **правая треть** кадра (высота 920 px), титры — левые 55%, фон #F4F6F8 с гигантской полупрозрачной иконкой приложения (водяной знак 8%). Финал — по центру. Никаких блюр-растяжек скриншотов на весь фон — это дёшево; только чистый фон + мокап.

Переходы slide/fade — не средствами Series, а внутри сцен (первые/последние 9–10 кадров: `interpolate` opacity/translateY), чтобы match-cut'ы (A3→A4, A9→A10) были под контролем.

### 6.3 Техника по слоям
- **Мокап-вход:** `spring({frame, fps, config:{damping:200, stiffness:120}})` на `translateY` и `scale`.
- **Ken Burns:** `interpolate(frame, [0, dur], [1, 1.06])` на scale + translate; для скринкастов — `<OffthreadVideo>` внутри экрана мокапа, `startFrom` для точного момента жеста.
- **Скриншоты:** `<Img src={staticFile('shots/schedule_today.png')}>`; видео-жесты: `<OffthreadVideo>` (не `<Video>` — быстрее рендер).
- **Титры:** компонент `<Title text=… accentWord=…>`; шрифт `@remotion/google-fonts/GolosText` → `const {fontFamily} = loadFont()`.
- **Тикающие секунды (A8):** не скринкастом целиком — берём PNG строки, секунды рендерим сами `<Seconds/>` (детерминированно, не зависит от записи); либо вырезаем окно секунд из скринкаста.
- **Янтарные акценты:** абсолютный `<div>`/SVG поверх мокапа, координаты подбираются по скриншоту один раз вручную (константы в сцене).
- **Аудио:** `<Audio src={staticFile('audio/track.mp3')} volume={fadeCurve}>`, SFX — отдельные `<Sequence>` с `premountFor`.
- **Превью:** Remotion Studio, рендер финала — `npx remotion render Promo9x16 out/promo_a_9x16.mp4` (H.264, CRF 18, fps 30).

### 6.4 Скиллы/доки при реализации
- `remotion-best-practices` — перед написанием первого компонента (обязательно).
- `remotion-docs` — точечные справки: `<OffthreadVideo>`, `@remotion/google-fonts`, springs.
- `remotion-multimedia` — аудио/SFX, видео в кадре.
- `remotion-studio` — отладка превью.
- `remotion-render` — финальный экспорт и настройки кодека.
- Локальный `mpk-build`/`mpk-dev` — если промо живёт внутри репозитория приложения, соблюдать его конвенции установки зависимостей.

## 7. Риски производства

### 7.1 Нет реальных скриншотов к дедлайну
**Митигейшн:** плейсхолдеры — скриншоты из Android Studio Preview / Compose-превью экранов; мокап и тайминги собираются на них сразу, реальные ассеты подменяются точечно (`staticFile`-пути уже заложены в сценах, замена = один файл). Ролик не блокируется: структура и тайминги от ассетов не зависят. Худший случай — статичные PNG везде, движение только камеры; сценарий это переживёт (Ken Burns заложен в каждую сцену).

### 7.2 Лицензия музыки
Брать только: Pixabay Music / Uppbeat (free tier с атрибуцией) / YouTube Audio Library — с явной коммерческой лицензией и сохранённым файлом лицензии в `promo/licenses/`. Никаких «популярных треков из TikTok». SFX — freesound.org CC0 или генерим сами. Если заказчик даёт свой трек — просим письменное подтверждение прав.

### 7.3 Персональные данные в кадре (важно!)
Скриншоты расписания/оценок/уведомлений могут содержать реальные ФИО студентов, имена преподавателей, оценки. По политике проекта (students.csv — чувствительные данные) **в промо не должно быть реальных ПД**: перед съёмкой заполнить демо-группу вымышленными данными (например, группа «ИС-99», предметы без персоналий) или заблюрить/заменить на постобработке. Проверить каждый кадр до рендера.

### 7.4 Прочее
- **Шрифты:** Golos Text — OFL, риск нулевой; не использовать платные без лицензии.
- **Скринкасты 30 fps вместо 60:** бегущие шевроны и точка звонка могут выглядеть дёргано → предпочитаем участки с плавным движением, либо дублируем анимацию шевронов сами поверх (SVG-оверлей) — запасной план сцены A4.
- **Разные разрешения устройств заказчика:** все сцены строятся от одного aspect ratio экрана; если скриншоты с разных телефонов — кадрируем `object-fit: cover`, мокап один.
- **Scope creep (45 с «а давайте ещё…»):** вариант Б уже зафиксирован по сценам; новые фичи — только в новую версию документа, не в текущий монтаж.
