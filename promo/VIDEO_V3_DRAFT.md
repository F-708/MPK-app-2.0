# VIDEO v3 — DRAFT босса (на критику стола переговоров)

Формат: 9:16 1080×1920 30fps, **30.0 s (900 кадров)**. Причина 30 вместо 15: читабельность.
Правило темпа: титул ≤34 символов, на экране ≥3.5 s (чтение RU ≈15 симв/с + запас); одна идея на сцену; никаких tri-cut и склеек чаще 2 s.

## Стиль (мой выбор)
- СВЕТЛАЯ, воздушная сцена как у продукта: фон #F7F9FB + огромный мягкий radial #E8F0FE; по низу — едва заметная сетка маршрутных линий #0072CE opacity .05.
- БЕЗ макета телефона: экран приложения = плавающая карточка со скруглением 44px, тень 0 30px 60px rgba(11,53,100,.18), лёгкая перспектива (rotateY ±4°, rotateX 2°) с easing; карточки въезжают/уезжают слайдом и scale .96→1 (spring damping 26).
- Акцент ОДИН: #0072CE (бренд). Янтарь УБРАН совсем. Титры: Golos Text 900, 96px, #0B3564, ≤2 строк, без плашек; время-суффикс сцены — JetBrains Mono 700 64px #0072CE («07:58») как narrativ-якорь «день студента».
- Переходы: cross-push 10 кадров (старая карточка уезжает влево-вниз 6%, новая приезжает справа) НА границах сцен; без фейдов кроме финала.
- Музыка: новый трек 30 s, 92 BPM (спокойнее), бит-якоря только для входов карточек, не для склеек каждые 0.6 s.
