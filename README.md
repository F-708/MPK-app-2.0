# Мой Политех

Расписание занятий колледжа МГПК под Android. Kotlin + Jetpack Compose.

Возможности:

- расписание по группам с офлайн-кэшем — документ разбирается по всем группам за один проход;
- виджеты: «до звонка», «сейчас/дальше», «расписание на сегодня», «звонки»;
- интерактивная карта колледжа с маршрутами между кабинетами;
- задания, оценки, материалы (PDF/DOCX/изображения) с аннотациями;
- каталог преподавателей с фото и расписанием каждого;
- уведомления о публикации свежего расписания и напоминания о заданиях;
- 7 цветовых тем; масштаб интерфейса; настройка подгрупп;
- автообновление из GitHub Releases (standard-сборка).

| `teacher` | `…​.teacher` | линия для преподавателей |

## Сборка

Нужны JDK 21 и Android SDK (compileSdk 36, minSdk 24).

```bash
export JAVA_HOME=/path/to/jdk21
export ANDROID_HOME=/path/to/android/sdk
./gradlew :app:testStandardDebugUnitTest   # юнит-тесты
./gradlew :app:assembleStandardRelease     # релизный APK
```

Подпись релиза читается из `keystore.properties` (в репозиторий не попадает).

## Структура

```
app/src/main/java/com/politex/
  data/        сеть, Room (v9), репозитории, модели
  ui/          Compose-экраны, компоненты, тема
  widget/      провайдеры виджетов, будильник, конфигуратор
  worker/      фоновая синхронизация (WorkManager)
  update/      автообновление из GitHub
  util/        звонки, уведомления, форматирование, настройки
```

## Обновления

standard-сборка раз в 12 часов проверяет `update.json` в корне репозитория,
при наличии новой версии скачивает APK и предлагает установить.
Порядок публикации — в [RELEASE.md](RELEASE.md).
